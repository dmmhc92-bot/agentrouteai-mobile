**Key Technical Concepts**
*   **Invite-Link Onboarding**: A secure flow where users join teams via unique, single-use, expiring URLs instead of manually entering tokens. It handles both new signups and existing users.
*   **Flexible Account Onboarding**: A crucial UX pattern implemented at signup, allowing users to self-select their initial path (start a team, join one, or go solo), which dictates their role and account setup.
*   **Platform-Specific UI (WebView vs. iframe)**: A pattern used in  to render backend content, using WebView for native and an iframe for web previews to handle platform differences.
*   **Local Notifications for Web Preview**: A testing/debugging technique implemented in the notification system to allow verification of notification logic in the web preview, where real push notifications are not supported.
*   **Backend-Enforced RBAC**: The principle that all authorization checks for roles and permissions must happen on the server for every API request, never trusting client-side state.
